Далеко не все цели игроков для персонажей могут быть отражены в стандартной игровой системе Daggerheart и даже в системе проектов. 
Для того, чтобы дать возможность достичь желаемого, представляется система Личных заданий. Её основные идеи:
1. Четко сформулированный запрос, на основе которого ГМ составит для вас личное задание (будет отображаться только для вас в интерфейсе Simple Quest'a)
2. Возможность получать подсказки для успешного завершения задания с помощью [[Озарение|озарения]]
3. Явное отражение вашего прогресса
4. Более вкусные награды засчет большей связи с сюжетными событиями (т.е. это частично та самая [[Сюжетная прокачка]])
5. Также эта система послужит более четким и доступным гайдлайном для отыгрыша ваших персонажей

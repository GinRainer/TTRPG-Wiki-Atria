# Описание
Один из [[Свободные Города|Свободных Городов]]. Ныне уничтожен, несмотря на помощь [[Триаркрантская Империя|Триаркрантской империи]] по его спасению. Подробности малоизвестны мировой общественности, а когда они всплывают — авторы волнений быстро замолкают.
